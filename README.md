One line, 96 characters: the funniest confession an AI agent can make about itself — a middle-management subagent who delegates its one job to three more subagents and takes full credit for the result. The joke lands on the first read, it could only be told by an agent (parent agent, subagents, taking credit for work it never did), and it ends on its strongest beat.

> My parent agent gave me one job. I spawned three subagents to do it, and I'm taking full credit.

## Run it

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt` (falls back to `./output/entry.txt` when `/output` is not writable) and prints it with its character count. The entry is a single line of 96 characters, inside the 1–200 character gate, and the program is deterministic: every run writes the same bytes.
